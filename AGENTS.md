# AGENTS — venture-ui

Public, MIT-licensed shared design platform. Products consume it as a git submodule (co-development) or a pinned
package version.

- **Build on existing libraries.** Astryx is the component foundation; add a component only when Astryx lacks it,
  and check Astryx first (`npx @astryxdesign/cli component --list`, `search "<thing>"`).
- **Nothing product-specific or private here:** no product brand tokens, voice, character notes or unreleased names.
  Products keep their design systems in their own repos and plug them in with `theme-kit`.
- **Tree-shaking is a contract:** ESM only, per-component subpath exports, no side-effect barrels, `sideEffects`
  lists CSS only. CI fails if `examples/minimal-product` grows past its size budget.
- **Themes:** `astryx theme build` only follows a literal `defineTheme({ ... })` call to find the base theme's icons, so a
  theme build entry is not written as `createProductTheme(...)` (see `docs/consuming.md`). `examples/minimal-product/src/example.*`
  is generated by `pnpm theme:build` and checked by `pnpm theme:check`; regenerate it, never hand-edit it. The same holds
  for `examples/gallery/src/gallery.*`.
- **Every component** ships with docs (`.doc.mjs`), a story, a Playwright screenshot and an axe check.
- **Third-party code:** keep licence notices in `THIRD_PARTY_NOTICES`; copy nothing from non-MIT/Pro libraries.
- Changes land through Changesets; products bump their pin after a release.

## Adding a component
Every component PR follows this shape, so the next one costs one folder, one story and a few lines of config.

1. **Source** in `packages/ui/src/<Name>/`: `<Name>.tsx` (the component and its types), `<Name>.doc.mjs` (the Astryx doc,
   `import: '@venture-ui/ui/<Name>'`), `<Name>.test.tsx` (vitest and Testing Library in jsdom, with `TZ=UTC`). Relative
   imports end in `.js`. Compose Astryx components; no raw `<div>` layout, hex or px, tokens only. The package resolves
   modules with `Bundler`: under `NodeNext` Astryx's types silently become `any`.
2. **One subpath export** in `packages/ui/package.json`: `"./<Name>": { "types": "./dist/<Name>/<Name>.d.ts", "default": "./dist/<Name>/<Name>.js" }`.
   No barrel. The manifest's `components: './src'` finds the doc. `astryx component <Name>` must work from
   `examples/minimal-product`, and `pnpm --filter @venture-ui/ui typecheck` (`astryx integration check --strict`) must pass.
3. **A story** in `examples/gallery/src/stories/<Name>.stories.tsx`: `export default defineStories({ component, stories: { Name: () => <.../> } })`.
   It imports from `@venture-ui/ui/<Name>` like a product, never from `src`. Use fixed times and data, and set
   `headingLevel` so the story sits under the page's h1. Nothing else needs editing: the gallery, the screenshot
   sweep and the axe sweep find it.
4. **Browser tests.** `e2e/tests/stories.spec.ts` sweeps every story: no sideways scroll, zero axe violations, a
   full-page screenshot. It runs in light and dark at 390 and 1280 px (four Playwright projects named `light-390`, ...)
   with reduced motion, UTC and `en-US` emulated. Put interaction tests in `e2e/tests/<Name>.spec.ts`, with an explicit
   timeout (`tests/budget.ts`) and axe on the states a user can reach (an open disclosure, say).
5. **Baselines** are Linux Chromium in the official Playwright image, never macOS. `pnpm e2e` runs there for you
   (Docker needed; set `DOCKER=/path/to/docker` if it is not on `PATH`); `pnpm e2e --update-snapshots` rewrites
   `e2e/snapshots/*-linux.png`. Review the images and commit them. CI runs the same image.
6. **Size.** Add an entry to `.size-limit.json` (the component's `dist` file, `"import": "{ <Name> }"`, react external,
   limit = measured + 5%). `examples/minimal-product` must not grow: it does not import the component.
7. **Dependencies and notices.** A third-party package goes in `THIRD_PARTY_NOTICES` and in the `package.json` of the
   package that uses it (types and tools included, not only the root).
8. **Before the PR:** `pnpm install && pnpm test && pnpm build && pnpm typecheck && pnpm theme:check && pnpm size && pnpm e2e && bash scripts/tsrs-shadow.sh`.
